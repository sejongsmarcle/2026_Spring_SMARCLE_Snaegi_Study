```cpp
#include <Servo.h>
#include <Adafruit_LiquidCrystal.h>

Servo s;
Adafruit_LiquidCrystal lcd(0);

int angle = 0;

void setup() {
  s.attach(7);

  lcd.begin(16, 2);
  lcd.setBacklight(1);

  lcd.setCursor(0, 0);
  lcd.print("Angle");
}

void loop() {
  for (angle = 0; angle <= 180; angle += 30) {
    s.write(angle);

    lcd.clear();
    lcd.setCursor(0, 0);
    lcd.print("Angle");

    lcd.setCursor(0, 1);
    lcd.print(angle);
    lcd.print("°");

    delay(1000);
  }


  delay(1000);
}
```

## 회로 설명

브레드보드를 사용하지 않고 LCD와 서보모터의 GND, VCC를 각각 아두이노의 GND, 5V에 직접 연결하였습니다.

또한 LCD의 SDA, SCL은 아두이노의 A4, A5에 연결하였고, 서보모터의 신호선은 디지털 핀 7번에 연결하였습니다.

## 코드 설명

팅커캐드의 LCD는 MCP 방식이기 때문에 Adafruit_LiquidCrystal.h 라이브러리를 사용하여 LCD를 제어하였습니다.

LCD는 16칸씩 두 줄로 설정하였고, loop() 함수에서 for문을 사용하여 서보모터의 각도를 0도부터 180도까지 30도씩 증가시켰습니다.

이때 LCD의 윗줄에는 Angle을 출력하고, 아랫줄에는 현재 각도와 ° 기호를 출력했으며

이때 각도는 delay(1000)을 사용하여 1초 동안 유지되도록 하였습니다.
