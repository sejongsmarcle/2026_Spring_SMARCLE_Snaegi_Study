## 2. 설정한 임계값

초음파 센서로 측정한 거리를 기준으로 신호등의 동작을 변경하였다.

- 4cm 이하: 센서가 정상적으로 물체를 감지하지 못하거나 너무 가까운 경우로 판단하여 LED를 모두 끈다.
- 4cm 초과 140cm 미만: 물체가 가까운 위치에 있으므로 빨간 LED를 켠다.
- 140cm 이상 330cm 미만: 물체가 비교적 먼 위치에 있으므로 초록 LED를 켠다.
- 330cm 이상: 센서 측정 범위 밖으로 판단하여 LED를 모두 끈다.

## 3. 동작 설명

초음파 센서 HC-SR04를 이용하여 물체와 센서 사이의 거리를 측정하였다.  
측정된 거리에 따라 신호등 LED의 동작이 달라지도록 조건문을 사용하였다.

물체가 가까운 범위에 있으면 위험 상황으로 판단하여 빨간 LED가 켜지고, 물체가 먼 범위에 있으면 안전한 상황으로 판단하여 초록 LED가 켜지도록 하였다.  
또한 물체가 너무 가깝거나 센서 범위 밖에 있는 경우에는 정확한 측정이 어렵다고 판단하여 두 LED를 모두 꺼지게 하였다.

## 4. 코드

```cpp
int red = 13;
int green = 11;

int trigPin = 7;
int echoPin = 6;

long duration;
float distance;

void setup() {

    pinMode(red, OUTPUT);
    pinMode(green, OUTPUT);

    pinMode(trigPin, OUTPUT);
    pinMode(echoPin, INPUT);

    Serial.begin(9600);
}

void loop() {

    digitalWrite(trigPin, LOW);
    delayMicroseconds(2);

    digitalWrite(trigPin, HIGH);
    delayMicroseconds(10);

    digitalWrite(trigPin, LOW);

    duration = pulseIn(echoPin, HIGH, 30000);

    // 감지 안 되면 0
    if (duration == 0) {
        distance = 0;
    }
    else {
        distance = duration * 0.034 / 2;
    }

    Serial.println(distance);

    // 부채꼴 밖 → 둘 다 꺼짐
    if (distance <= 4) {

        digitalWrite(red, LOW);
        digitalWrite(green, LOW);
    }

    // 가까운 절반 → 빨간불
    else if (distance < 140) {

        digitalWrite(red, HIGH);
        digitalWrite(green, LOW);
    }

    // 먼 절반 → 초록불
    else if (distance < 330) {

        digitalWrite(red, LOW);
        digitalWrite(green, HIGH);
    }

    // 범위 밖 → 둘 다 꺼짐
    else {

        digitalWrite(red, LOW);
        digitalWrite(green, LOW);
    }

    delay(200);
}
```

## 5. 결과 설명

실행 결과, 초음파 센서 앞에 있는 물체의 위치에 따라 LED 상태가 달라지는 것을 확인하였다.

물체가 약 109.6cm 위치에 있을 때는 140cm보다 작으므로 빨간 LED가 켜졌다.  
물체가 약 252.1cm 위치에 있을 때는 140cm 이상 330cm 미만이므로 초록 LED가 켜졌다.  
물체가 센서와 너무 가깝거나 감지 범위를 벗어난 경우에는 두 LED가 모두 꺼졌다.

따라서 초음파 센서의 측정값을 이용하여 조건에 따라 신호등의 동작을 변경하는 회로를 구현할 수 있었다.
