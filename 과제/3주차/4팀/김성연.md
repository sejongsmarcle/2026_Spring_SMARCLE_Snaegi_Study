프로젝트명
스마트 주차 보조 시스템 (Parking Assist System)

프로젝트 목적
자동차가 주차할 때 장애물과의 거리를 측정하고, 그 거리를 LED와 부저를 이용해 직관적으로 알려주는 시스템을 제작한다.
실제 차량의 후방 주차 센서를 간단하게 구현하는 것이 목표이다.

프로젝트 핵심 기능
1. 거리 측정
초음파 센서를 이용하여 장애물까지의 거리를 측정한다.

2. LED 상태 표시
거리 구간에 따라 RGB LED 색상이 변한다.

50cm 이상 → 초록색 (안전)
20~50cm → 노란색 (주의)
10~20cm → 빨간색 (위험)
10cm 이하 → 빨간색 깜빡임 (매우 위험)

3. 부저 경고
장애물에 가까워질수록 부저 소리가 빨라지도록 설계하였다.

4. 시리얼 입력 기능
틴커캐드 환경에서는 초음파 센서를 통한 거리 측정이 제한되기 때문에 시리얼 모니터를 통해 사용자가 직접 거리를 입력할 수 있도록 구현하였다.

예시
70
30
15
5

사용 부품
- 아두이노 UNO
- 초음파 센서
- RGB LED
- 피에조 부저
- 220Ω 저항

회로 연결

초음파 센서
+ → 5V
- → GND
SIG → D10

RGB LED
R → D13
G → D5
B → D7
공통 핀 → GND

(각 LED 핀에는 220Ω 저항 사용)

피에조 부저
+ → D11
- → GND

코드 작동 원리

1. 핀 설정
각 부품이 연결된 핀 번호를 변수로 저장한다.

2. setup()
시리얼 통신을 시작하고 LED와 부저 핀을 출력 모드로 설정한다.

3. 초음파 센서 거리 측정
초음파를 발사한 뒤 돌아오는 시간을 측정하여 거리를 계산한다.

거리 계산 공식
distance = duration * 0.034 / 2

소리 속도를 이용하여 cm 단위 거리로 변환한다.

4. 시리얼 입력 처리
시리얼 모니터에 숫자를 입력하면 해당 숫자를 거리값으로 사용한다.

예시
25 입력 → 거리 25cm로 동작

5. 거리 구간 판별
측정된 거리값에 따라 안전, 주의, 위험, 매우 위험 상태로 구분한다.

6. LED 제어
거리 상태에 따라 RGB LED 색상을 변경한다.

7. 부저 제어
거리가 가까워질수록 더 빠른 경고음을 출력한다.

전체 동작 과정

거리 측정
→ 거리 계산
→ 거리 상태 판별
→ LED 색 변경
→ 부저 경고음 출력
→ 시리얼 모니터 출력

프로젝트 의의
이 프로젝트는 센서 데이터를 기반으로 LED와 부저를 제어하는 시스템으로, 임베디드 프로그래밍과 센서 제어의 기초 원리를 학습할 수 있다.
또한 이후 자율주행, OpenCV, Raspberry Pi 등의 심화 프로젝트로 확장 가능하다.


// ===============================
// 주차 보조 시스템
// ===============================

// ---------- 핀 설정 ----------
const int sigPin = 9;

const int buzzerPin = 3;

const int redPin = 11;
const int greenPin = 5;
const int bluePin = 6;

// ---------- 변수 ----------
long duration;
float sensorDistance;
float distance;

bool useSerialDistance = false;

void setup() {

  Serial.begin(9600);

  pinMode(buzzerPin, OUTPUT);

  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);

  Serial.println("=== Parking Assist System ===");
}

void loop() {

  // ==========================
  // 초음파 거리 측정
  // ==========================

  pinMode(sigPin, OUTPUT);

  digitalWrite(sigPin, LOW);
  delayMicroseconds(2);

  digitalWrite(sigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(sigPin, LOW);

  pinMode(sigPin, INPUT);

  duration = pulseIn(sigPin, HIGH);

  sensorDistance = duration * 0.034 / 2;

  // ==========================
  // 시리얼 입력 거리 설정
  // ==========================

  if (Serial.available() > 0) {

    String input = Serial.readStringUntil('\n');

    input.trim();

    if (input.length() > 0) {

      distance = input.toFloat();

      useSerialDistance = true;

      Serial.print("수동 거리 설정: ");
      Serial.print(distance);
      Serial.println(" cm");
    }
  }

  // 시리얼 입력 없으면 센서값 사용
  if (!useSerialDistance) {
    distance = sensorDistance;
  }

  // ==========================
  // 거리 출력
  // ==========================

  Serial.print("Sensor Distance: ");
  Serial.print(sensorDistance);
  Serial.println(" cm");

  Serial.print("Current Distance: ");
  Serial.print(distance);
  Serial.println(" cm");

  // ==========================
  // LED + 부저 제어
  // ==========================

  // 안전
  if (distance >= 50) {

    setColor(LOW, HIGH, LOW);

    noTone(buzzerPin);
  }

  // 주의
  else if (distance > 20) {

    setColor(HIGH,HIGH,LOW);

    tone(buzzerPin, 1000);
    delay(100);
    noTone(buzzerPin);
  }

  // 위험
  else   {

    setColor(HIGH, LOW, LOW);

    tone(buzzerPin, 1500);
    delay(80);
    noTone(buzzerPin);
  }

 

  Serial.println("----------------");

  delay(300);
}

// ==========================
// RGB LED 제어 함수
// ==========================

void setColor(bool r, bool g, bool b) {

  digitalWrite(redPin, r);
  digitalWrite(greenPin, g);
  digitalWrite(bluePin, b);
}
